# QuizMaster – Online Quiz Management System

## 🚀 Live Demo

**Visit the deployed application here:**

**https://quiz-master-main-production-895d.up.railway.app**

---

## Overview

QuizMaster is a full-stack web application built using Flask that enables educational institutions to create, manage, and conduct online quizzes efficiently. The platform provides separate dashboards for administrators, teachers, and students, making quiz management simple and organized.

---

## Features

### Admin

* Manage users (Teachers & Students)
* Create and manage subjects
* Monitor platform activities
* View overall system statistics

### Teacher

* Create and manage subjects
* Add chapters for each subject
* Create quizzes
* Add, edit, and delete MCQ questions
* Upload study notes (PDF/DOC/DOCX)
* View quiz analytics and student performance

### Student

* Register and log in securely
* Browse available subjects and quizzes
* Attempt quizzes
* View scores instantly
* Track previous quiz attempts
* Access uploaded study materials

## Installation

```bash
git clone https://github.com/yourusername/QuizMaster.git
cd QuizMaster

python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt

python app.py
```

Open your browser:

```text
http://127.0.0.1:5000
```
